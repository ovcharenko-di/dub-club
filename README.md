# 🎙️ Dub Club

Голосовая пати-игра в браузере в духе «The Choicer Voicer»: слушаешь реплику, повторяешь её в микрофон, а жюри ставит оценки.

Без сервера, без сборки и без аккаунтов: всё работает локально в браузере.

## Возможности

- **Игра на 1–4 игроков** у одного микрофона, по раундам; жюри оценивает все дубли в финале.
- **Жюри из трёх судей** анализирует запись и сравнивает её с оригиналом:
  - 🎼 *Маэстро Тон* оценивает мелодию интонации и высоту голоса (определение тона алгоритмом YIN);
  - ⏱️ *Мадам Тайминг* оценивает темп, длительность и ритм слогов (огибающая громкости + DTW-выравнивание);
  - 🕶️ *Дядя Вайб* оценивает подачу, громкость и общее попадание (и немного своё настроение).
- **Демо-пак «Голосовые трюки»**: реплики синтезируются прямо в браузере (злодейский смех, сирена, робот и т. д.).
- **Свои паки**: аудио- и видеофайлы с выбором отрезка или реплики, записанные с микрофона. Паки хранятся в IndexedDB браузера.
- **Редактор реплик**: загрузи видео, нарежь его на реплики прямо на таймлайне (с волной звука) и подпиши их субтитрами — вручную или импортом `.srt`/`.vtt`. Готовый пак сохраняется в браузере и выгружается одним `.zip`-файлом (видео + `pack.json` + `subtitles.srt`), который друзья импортируют у себя. В игре текст реплики показывается суфлёром поверх видео.
- **Режим дубляжа**: загрузи видео, переозвучь отрезок своим голосом (оригинальный звук можно оставить фоном), посмотри результат и скачай его как видео (WebM) или только голос.

## Запуск

Нужен любой статический HTTP-сервер (ES-модули и микрофон не работают через `file://`):

```bash
python3 -m http.server 8000
# или
npx serve .
```

Затем откройте http://localhost:8000. Для доступа к микрофону страница должна открываться через `localhost` или `https`. Подходит GitHub Pages: стабильная версия из `develop` лежит на https://ovcharenko-di.github.io/dub-club/, а остальные ветки — на https://ovcharenko-di.github.io/dub-club/branches/.

Лучше всего работает в Chrome, Edge и Firefox. Играйте в наушниках, чтобы оригинал не попадал в микрофон.

## Структура

```
index.html
css/style.css
js/
  main.js          — навигация между экранами
  audio.js         — микрофон, запись, декодирование, воспроизведение
  analysis.js      — извлечение признаков (тон, громкость) и сравнение через DTW
  judges.js        — судьи, их критерии и реплики
  packs.js         — демо-пак (синтез), хранение своих паков
  stage.js         — «сцена»: волна или видео реплики (+ суфлёр)
  timeline.js      — таймлайн редактора: волна, реплики, перетаскивание
  subtitles.js     — разбор .srt/.vtt и запись .srt
  zip.js           — минимальный ZIP для экспорта/импорта паков
  ui.js            — мелкие DOM-хелперы
  screens/         — меню, настройка игры, игра, паки, редактор, дубляж
```

Проект независимый и не использует ассеты оригинальной игры.
